# Phase 12 Gate C security report

Date: 2026-11-23  
Scope: REQ-15, NFR-013, NFR-017, Gate C

## Result

Gate C passes by source inspection and existing regression evidence. CI now
scans full Git history with the pinned Gitleaks 8.28.0 release, verifies its
SHA-256 release checksum, redacts findings, and reports only their count. The
scan runs on code changes; a non-zero finding count blocks CI.

The local agent environment did not permit invoking Gitleaks. The first branch
CI run must provide the scan result before merge. No unresolved source finding
was identified during this audit.

## Public transport and least privilege

`docs/runbooks/self-host-home.md` requires public endpoints to use an HTTPS
tunnel and recommends a stable named Cloudflare tunnel. Metrics remain
loopback-only. The Git sandbox grants writes only to its workspace and grants
network access only to network Git commands through the guarded CONNECT proxy.

## Findings

No unresolved Gate C finding was identified. CI scan confirmation remains a
pre-merge operational check, not an accepted exception.
